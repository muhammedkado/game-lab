# Game Lab · مختبر الألعاب

Ten original browser games, each in the genre of a game trending on Google Play and the App Store in November 2026,
redesigned around what players complained about: no ads, every level solvable, free help.

Play: https://muhammedkado.github.io/game-lab/

- `index.html`: the lab page (Arabic, RTL).
- `games/<name>/`: each game as a static folder (open `index.html`; works offline).

The games are original. Names of the games that inspired them are trademarks of their owners and appear only to cite the market data.
Built with [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) (MIT). Font: Almarai (SIL OFL 1.1).
